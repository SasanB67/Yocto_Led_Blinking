Description: Controls three LEDs connected to different Raspberry Pi GPIO pins. Each LED blinks at a different interval: 1, 2, and 3 seconds.

Required HW: Raspberrypi3-64

Pin connections and wiring:
- GPIO17 (physical pin 11): Connect to a 220–330 Ω resistor, then to LED 1 positive leg.
- GPIO27 (physical pin 13): Connect to a 220–330 Ω resistor, then to LED 2 positive leg.
- GPIO22 (physical pin 15): Connect to a 220–330 Ω resistor, then to LED 3 positive leg.
- GND (physical pin 6): Connect to the negative leg (cathode) of all three LEDs.
